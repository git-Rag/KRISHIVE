# KRISHIVE
Offline AI Farming Assistant for Smart, Accessible Agriculture

## Overview
KRISHIVE is an AI-powered farming assistant designed to help farmers make data-driven decisions, even without constant internet access.

It focuses on accessibility, simplicity, and reliability in low-resource environments.

## Features
- Crop recommendation based on soil and conditions
- Fertilizer suggestions for optimal yield
- Plant disease detection using AI
- Voice-based interaction for ease of use
- Offline-first design for rural connectivity challenges

## Problem Statement
Farmers often lack access to real-time, reliable agricultural guidance. Existing tools depend heavily on internet connectivity and are not optimized for local use cases.

## Solution
KRISHIVE provides an intelligent assistant that works offline and delivers actionable insights using pre-trained models and lightweight data processing.

## Setup Instructions

### Backend
1. Navigate to backend folder
2. Create virtual environment
3. Install dependencies
4. Create a .env file using .env.example
5. Run the server

### Frontend
1. Navigate to frontend folder
2. Install dependencies
3. Start development server
